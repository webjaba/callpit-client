# callpit client

Минималистичный терминальный клиент для голосовых комнат `calls`. Клиент использует HTTP и WebSocket только для авторизации, присутствия и signaling. Аудио передаётся напрямую между участниками через WebRTC.

## Требования

- Go 1.26.5;
- C compiler для сборки `malgo`;
- macOS с CoreAudio или Linux с PulseAudio/ALSA/PipeWire compatibility layer;
- доступ к HTTPS/WSS public listener сервера.

## Конфигурация

При первом запуске клиент создаёт файл:

- macOS: `~/Library/Application Support/calls/config.json`;
- Linux: `$XDG_CONFIG_HOME/calls/config.json` или `~/.config/calls/config.json`.

Заполните обязательные поля:

```json
{
  "access_token": "1:<secret>",
  "input_device_id": null,
  "output_device_id": null
}
```

Клиент подключается к зафиксированному в коде адресу `http://localhost:8080`. Для изменения адреса требуется пересборка клиента. Токен хранится в файле с правами `0600` и передаётся только в заголовке `Authorization: Bearer`. `null` выбирает системное аудиоустройство. Конкретные устройства можно сохранить через окно настроек.

## Запуск

```bash
make run
```

После изменения конфига нажмите `l`. Повторное нажатие полностью закрывает текущее WebSocket/WebRTC-состояние, заново проверяет токен и повторно входит в активную комнату.

## Управление

| Клавиша | Действие |
|---|---|
| `Esc` | Перейти из ввода текста в навигацию |
| `/` | Выбрать строку комнаты и включить ввод текста |
| `←`, `→`, `↑`, `↓` | Пространственная навигация вне ввода текста |
| `Tab`, `Shift+Tab` | Следующий или предыдущий элемент в режиме навигации |
| `Enter` | Активировать кнопку или начать ввод в выбранном поле |
| `l` | Логин или полное переподключение вне строки комнаты |
| `m` | Включить или выключить микрофон |
| `d` | Включить или выключить входящий звук |
| `s` | Настройки аудиоустройств |
| `x` | Покинуть звонок |
| `q` | Закрыть клиент вне строки комнаты |
| `Ctrl+C` | Закрыть клиент из любого элемента |

В режиме ввода текста клавиши, включая стрелки, передаются активному полю. `Enter` в строке комнаты подключает к комнате. Оранжевая рамка обозначает ввод текста, синяя — элемент, выбранный для навигации.

В Settings первым пунктом доступен Access key. Значение вводится в скрытом поле и сохраняется в `config.json`. После успешного изменения клиент завершает текущий звонок и сбрасывает авторизацию; для проверки и применения нового ключа нажмите Login.

## Ограничения

- состояние mute/deafen локальное и не передаётся другим участникам;
- после любого обрыва состояние вызова удаляется, ручное переподключение выполняется клавишей `l`;
- один пользователь может отображаться несколькими карточками, потому что каждое подключение имеет отдельный `peer_id`;
- без TURN соединение может не установиться в сетях со сложным NAT;
- первая версия передаёт mono Opus и воспроизводит общий stereo mix.
